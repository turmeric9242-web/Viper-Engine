Drop your own textures here: .png, .bmp or .tga (PNG: non-interlaced).
They show up in the editor's texture picker (select an object, press T) next to the built-in ones:
grass, dirt, stone, brick, wood, sand, metal, tiles, checker.
A file with the same name as a built-in (e.g. textures/brick.png) replaces that built-in.
Tip: power-of-two sizes (64, 128, 256, 512) look best; textures repeat across the object.
In a .vscene file:   texture brick   and   tile 2   (tile = repeats per world unit)
